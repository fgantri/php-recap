Shell Cheat Sheet

Not just what to type — what each command is, because that's what makes the rest guessable.

What happens when you press Enter

1–4Expansion — split into words; expand ~, $VAR, $(cmd), globs like *.php
5–6Strip quotes; set up redirections
7Is word 1 a builtin? If so run it in-process and stop
8Otherwise walk $PATH left to right; first match wins
9–11fork() → exec() → parent waits and collects the exit code

Expansion happens before the program sees anything. rm * is dangerous because rm never sees * — bash already replaced it with every filename.

Navigation and inspection

pwdWhere am I
cd -Back to the previous directory
ls -lahLong, all (incl. hidden), human sizes
ls -liShow inode numbers — proves hard links share one
tree -L 2Directory tree, two levels deep
find . -name '*.php'Find by name, recursively
du -sh *Size of each entry here
df -hFree disk space
file XWhat is this, by magic bytes — not by extension
stat XThe inode's contents
xxd X | headRaw bytes as hex

Finding out what a command is

which phpFirst match on $PATH
which -a phpEvery match, in search order — finds the imposter
type cdBuiltin? alias? function? file?
command -v phpThe portable, script-safe form
hash -rClear bash's lookup cache after installing something
echo $PATH | tr ':' '\n'The search list, one per line

Streams, redirection, pipes

fdStreamCarries
0stdinInput
1stdoutResults — the thing the command produces
2stderrDiagnostics — errors, progress, warnings
 
cmd > out.txt         # stdout to file (truncate)
cmd >> out.txt        # stdout to file (append)
cmd 2> err.log        # stderr to file
cmd > out 2>&1        # both to one file
cmd 2> /dev/null      # discard errors
cmd < in.txt          # file as stdin
a | b                 # a's STDOUT to b's stdin — stderr is NOT carried
a 2>&1 | b            # pipe both
cmd | tee f.txt       # to screen AND file

The rule that makes tooling composable: results on stdout, diagnostics on stderr. A CLI that prints progress to stdout poisons every pipeline it's used in.

Exit codes and chaining

echo $?               # exit code of the last command
a && b                # run b only if a succeeded (0)
a || b                # run b only if a failed (non-zero)
a ; b                 # run b regardless

Zero means success — one way to succeed, many ways to fail. Start every script with:

set -euo pipefail
-eExit on any command failing
-uError on an undefined variable — catches typos in names
-o pipefailA pipeline fails if any stage fails, not just the last

Quoting

name=world
echo "hello $name"    # hello world  — double quotes expand
echo 'hello $name'    # hello $name  — single quotes are literal
echo "$(date)"        # command substitution
"$var"                # ALWAYS quote variables — unquoted splits on spaces

Same rule as PHP's quotes, one layer down. Quoting marks a region as data rather than code — the identical principle behind HTML escaping and prepared statements.

Processes and ports

php -S localhost:8888 &      # run in background
jobs                         # background jobs of this shell
fg %1 / kill %1              # foreground / kill job 1
ps aux | grep php            # find processes
kill -9 PID                  # force kill

ss -ltnp                     # what is listening, and which PID
ss -ltnp | grep 8888         # who has my port? (the 'Address already in use' answer)
lsof -i :8888                # same, if lsof is installed

ls -l /proc/PID/fd           # a process's open file descriptors
cat /proc/PID/environ | tr '\0' '\n'
strace -e trace=network php server.php   # watch the syscalls

Text

grep -rn 'pattern' .         # recursive, with line numbers
grep -i / -v / -c            # case-insensitive / invert / count
head -20 f / tail -f f       # first 20 lines / follow a log live
wc -l f                      # count lines
sort | uniq -c | sort -rn    # frequency count, most common first
cut -d' ' -f1                # field 1, space-delimited
sed 's/old/new/g' f          # substitute

Keys worth having in your fingers

Ctrl+CInterrupt the foreground process
Ctrl+DEnd of input — exits the shell
Ctrl+RSearch command history — the highest-value one here
Ctrl+LClear the screen
Ctrl+A / EStart / end of line
Ctrl+WDelete the previous word
Alt+.Insert the last argument of the previous command

WSL specifics
