PHP Cheat Sheet

Syntax, superglobals, arrays, PDO — and the traps, which are the part worth rereading.

Tags and structure

<?php … ?>        // code block; everything outside passes through
<?= $v ?>         // short echo — the standard way to output in a template
                  // omit the closing ?> in PHP-only files (stray bytes break headers)

declare(strict_types=1);   // first statement. use it in every file

Alternative syntax — use in views

<?php if ($read): ?>   … <?php else: ?>   … <?php endif; ?>
<?php foreach ($books as $book): ?>   … <?php endforeach; ?>
<?php while (…): ?>   … <?php endwhile; ?>

Convention: braces in logic files, colons in view files.

Falsy, exhaustively: false 0 0.0 -0.0 '' '0' [] null. Everything else is truthy. Default to ===.

$a ?? $b       // null/undefined → $b. no warning. PREFER THIS
$a ?: $b       // any falsy → $b. eats a legitimate 0
$a ??= $b      // assign if not set
$o?->m()       // null instead of an error

Arrays

$a = ['x' => 1, 'y' => 2];
$a[] = $v;                       // append, next integer key
$a['k'] ?? 'default';            // safe read
[$x, $y] = $pair;                // destructuring
['x' => $x] = $a;                // keyed destructuring
$merged = [...$a, ...$b];        // spread (8.1+ for string keys)

Three array traps

1. array_filter preserves keys → json_encode emits an object {"2":…} instead of an array. Wrap in array_values().

2. in_array defaults to loose comparison. Always pass true as the third argument.

3. After foreach ($a as &$v), always unset($v); — otherwise the next loop overwrites the last element repeatedly.

Functions and closures

function f(int $a, string $b = 'x', ...$rest): ?array { }

$fn  = function ($x) use ($captured) { … };   // explicit capture, by value
$fn  = function ($x) use (&$live) { … };      // by reference — rarely right
$fn  = fn ($x) => $x * $captured;             // auto-capture, by value, one expression
$ref = strlen(...);                            // first-class callable (8.1+)

PHP functions cannot see enclosing scope. Pass it in, or capture it explicitly.

Classes

final class Note
{
    public const STATUS_DRAFT = 'draft';       // UPPER_SNAKE, via ::

    public function __construct(
        public readonly int $id,               // promoted + immutable (8.1+)
        private string $body = '',
    ) {}

    public function body(): string { return $this->body; }

    public static function make(int $id): self { return new self($id); }
}

$n = new Note(1, 'hello');
echo $n->id;                  // no $ after the arrow
echo Note::STATUS_DRAFT;      // :: reaches into the class itself

public anywhere · protected this class and subclasses · private this class only.

Superglobals

$_SERVERRequest and server info — CGI variable names
$_GETThe query string, parsed — regardless of method
$_POSTForm-encoded body. Empty for JSON bodies — use file_get_contents('php://input')
$_COOKIECookies the browser sent
$_SESSIONServer-side, after session_start()
$_FILESUploads
$_REQUESTMerged GET/POST/cookie — avoid, the ambiguity causes bugs

Everything except $_SESSION and $_ENV is attacker-controlled.

PDO

$dsn = 'mysql:host=localhost;port=3306;dbname=myapp;charset=utf8mb4';

$pdo = new PDO($dsn, $user, $pass, [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,  // throw, don't fail quietly
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,        // no duplicate numeric keys
    PDO::ATTR_EMULATE_PREPARES   => false,                   // real prepares; native types back
]);

// named — clearer past two parameters
$stmt = $pdo->prepare('SELECT * FROM notes WHERE user_id = :uid AND id = :id');
$stmt->execute(['uid' => $uid, 'id' => $id]);

$row  = $stmt->fetch();       // one row, or FALSE when none
$rows = $stmt->fetchAll();    // array of rows, [] when none
$id   = $pdo->lastInsertId();
$n    = $stmt->rowCount();    // affected rows for INSERT/UPDATE/DELETE
The three settings above are not optional

ERRMODE_EXCEPTION — without it, a failed query returns false and your code carries on with nonsense.

EMULATE_PREPARES => false — with emulation on, integer columns come back as strings, so $row['user_id'] !== $currentUserId is true even for the rightful owner. This silently breaks ownership checks.

fetch() returns false when there is no row — a boolean where you expected an array. Handle it immediately: if (! $row) { abort(404); }

Placeholders bind values, never identifiers. Table and column names cannot be parameterised — validate them against an explicit allowlist.

Output and escaping

function e(?string $v): string {
    return htmlspecialchars($v ?? '', ENT_QUOTES, 'UTF-8');
}

<?= e($note['body']) ?>                    // HTML text
<input value="<?= e($name) ?>">            // attribute — ALWAYS quote it
?q=<?= urlencode($q) ?>                    // URL parameter
<script>const x = <?= json_encode($v, JSON_HEX_TAG|JSON_HEX_AMP) ?>;</script>

Files and views

require  // fatal if missing; loads every time
require_once / include_once   // loads at most once — use for functions and classes
include  // warning if missing; execution continues

$config = require 'config.php';   // a required file can RETURN a value

ob_start(); require $view; $html = ob_get_clean();   // capture output as a string

Debugging

function dd($v) { echo '<pre>'; var_dump($v); echo '</pre>'; die(); }

var_dump($v)    // types, lengths, structure
print_r($v)     // readable, no types
var_export($v)  // valid PHP source — paste into a test
error_log($m)   // when output would break the response

php -l file.php                 // syntax check without running
php -d display_errors=1 -d error_reporting=E_ALL file.php
php -a                          // interactive shell
php -S localhost:8888 -t public // dev server with a document root
